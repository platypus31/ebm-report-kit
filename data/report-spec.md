# EBM 報告內容結構規格（簡報生成的權威規範）

> 本規格歸納自多份臺灣醫院實際 EBM 報告的共同結構，已抽象化為通用規範。
> 版面風格權威＝White Grey 引擎（`skills/ebm-slides.md`）；本檔管內容結構。

## §1 核心不變量（生成時視為硬規格）

1. **6A 骨架＋導航過場**：Analysis → Ask → Acquire → Appraise → Apply → Audit；每階段切換插入「EBM 的步驟」高亮過場頁（當前階段強調）。
2. **首尾呼應**：開場是一位具體病人（病史＋病人/家屬的原話提問），結尾「臨床回覆」回到同一位病人、用白話逐一回答開場的每個提問——中間所有內容都為了它。
3. **評讀是最大段落**（佔 33–40%），一題兩頁節奏：題目頁（題號＋中英題目＋三態勾選 Yes/No/Can't tell＋評論）→ 佐證頁（原文截圖＋紅框標關鍵句＋頁碼）。
4. **證據可視化**：任何「本研究如何」的宣稱必配原文截圖＋紅框；沒佐證的宣稱等於沒講。
5. **檢索逐庫成對**：每個資料庫＝「策略頁（關鍵字＋技巧）→ 結果頁（截圖＋`Results: N / Corresponding: M` 雙計數）」；0 篇照登。
6. **PRISMA 匯流圖**收攏所有資料庫（Identification → 去重 → 篩選 → 納入）。
7. **文獻比較 MPICOT＋紅黃綠燈**（Method/P/I/C/O/Time 六欄，逐篇評級），最佳文獻明講選文理由（符合 PICO／全文／樣本數／設計）。
8. **OCEBM 2011 等級頁**標本文落點，全篇擺位一致（建議評讀尾）。
9. **Apply＝逐項核對＋共享決策＋白話回覆**：applicability 清單（年齡/性別/種族/病況/時序逐項比對）；治療型用 SDM 4E（Evidence/Expectation/Expertise/Environment）、診斷型用 3E＋Apply 3 題；缺口主動查證補洞（仿單/在地資料）。
10. **AUDIT 五面向自評＋效率評估**（題組見 `data/slide-snippets.json`，答案各報告自填、時數留白）。

## §2 流程與張數配比

| 段落 | 內容 | 張數基準 |
|---|---|---|
| 封面＋分工 | 標題/報告者/指導老師/日期；團報附工作分配表 | 1-2 |
| ANALYSIS | 臨床情境敘事卡（textcard）＋「本報告要回答的問題」清單 | 2-3 |
| ASK | 背景衛教（現行共識＋knowledge gap，可配 1-2 頁圖解）→ 臨床問題＋五型勾選 → 型別權威表（table）→ PICO 三欄表（table） | 6-9 |
| ACQUIRE | 6S 階層 → 檢索目標＋PICO 表重貼 → 逐庫成對＋迭代紀錄 → PRISMA → MPICOT 紅黃綠燈 → 選定文獻刊頭頁 → 選文理由 | 10-16 |
| APPRAISE | 工具宣告（按型別選 CASP）→ 逐題兩頁 → 結果雙層總結 → OCEBM | 18-30（最大段落） |
| APPLY | applicability 核對 → 在地考量＋SDM → 臨床回覆 textcard | 5-8 |
| AUDIT | 五面向（可一面向一頁）＋效率評估 | 3-6 |
| 結尾 | References（Vancouver＋PMID）＋Thanks | 1-2 |

總張數落點 45–70；評讀佔比 35% 上下（偏離 ±10% 回頭檢查漏段）。

## §3 問題型別分流（生成前必先分型；權威表見 `data/glossary.md`）

| 面向 | 治療型-RCT | 治療型-SR/MA | 診斷型 | 預後/世代 |
|---|---|---|---|---|
| 工具 | CASP RCT 10 題 | CASP SR 10 題 | Diagnostic worksheet 4 題＋VIP | CASP Cohort 12 題（5a/5b、6a/6b 拆題） |
| 方法重點 | 隨機/盲化/ITT/基線可比 | 檢索完整性/RoB/逐 outcome 異質性選模（I²<50% fixed、≥50% random） | 代表性/金標準獨立盲性/可複製 | 選樣/測量/混雜因子（含 negative control 設計）/追蹤完整長度 |
| 結果呈現 | 效應量＋95%CI＋p；NNT 白話化 | forest plot＋異質性表 | 2×2＋kappa→Sn/Sp→LR±→post-test probability 計算鏈 | aHR/RR＋95%CI；CI 寬窄評精確度 |
| Apply 額外 | SDM 4E | ＋高異質性的謹慎結論 | 3E＋Apply 3 題＋院內可近性 | 觀察性證據力上限明講＋與其他證據吻合度（二次搜尋） |

## §4 原則（紅線）

- **誠實優先**：Can't tell 誠實勾、0 篇照登、高異質性直說信心下修、原文未提及的照標「未提及」、檢索放寬過程如實記——評讀的可信度全部來自這裡。
- **數字必須白話化**：至少一處 NNT 口語（「每 N 人有 1 人…」）或 post-test probability 的臨床語意；**結果頁必雙層**（統計意義：p＋CI 過中線/寬窄；臨床意義：ARR/NNT 或 LR 鏈）。
- **NNT 算不出來就明講**：原文未提供分組事件數時寫「無法換算」，絕不編造。
- **一頁一論點**：每頁至少一行文字論點（禁純圖片頁）；評讀題寧可兩頁不擠一頁。
- **數據自檢**：同頁並列的兩組數據逐字全同＝抄錯；效應量與備忘稿口徑一致。
- **語言分工**：標題/評論中文、評讀題目中英對照、檢索式/MeSH/數據英文原文、場景與臨床回覆全中文。
- **檢索數字可重現**：簡報上的每個檢索數字都來自真跑的搜尋（照式子重搜可得同量級結果）。

## §5 反例庫（生成與驗收時逐條對照）

| # | 反例 | 判準 |
|---|---|---|
| N1 | 同頁並列兩組數據逐字全同 | 生成 gate 掃；必為複製錯誤 |
| N2 | 開場病人的提問，結尾臨床回覆沒有逐一回答 | 收工檢查第一條 |
| N3 | 評讀頁純圖片、無題號無題目文字 | 每張評讀頁必有題號＋題目 |
| N4 | 備忘稿殘留模板殘渣（與本題無關內容） | notes 只放本頁講稿 |
| N5 | 只報 p 值不報 CI 寬窄；只報統計顯著不換算臨床意義 | 結果頁雙層強制 |
| N6 | 問題型別勾選列漏「預防型」（只印四型） | 五型勾選 |
| N7 | 評讀語氣全盤否定或全盤護航 | 平衡報導：強弱點並陳 |
| N8 | OCEBM 等級頁擺位全篇不一致 | 統一評讀尾 |
| N9 | 背景頁整頁截圖長文不可讀；或背景問題誤開成 PICO 專案 | 截圖配一行結論；背景/前景先分流 |
| N10 | AUDIT 逐題流水帳拖過多頁 | 精簡；效率評估必留 |
